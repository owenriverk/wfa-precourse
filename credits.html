Where the pictures come from.

The scene on each course page is an original pixel-art illustration, drawn for that page in the same style as the practice sims — no stock photos. Anything we didn’t draw ourselves gets named below, with a link back to the original.

Every hero image now on the course pages is our own pixel art, generated from tools/niche_pixel.py in this site’s repository. Earlier versions used Creative Commons photographs from Wikimedia Commons; none remain in use, and we thank those photographers all the same.
